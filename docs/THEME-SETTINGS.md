# Bitsy Auto – theme editor settings

Shopify allows each app block and app embed at most **75 settings** and **6 headings**, so Bitsy's settings are split the way a theme splits theme settings and section settings. Everything is generated by `scripts/build-theme-blocks.py`; edit that and run it, rather than editing `blocks/*.liquid`.

| In the theme editor | Name | Type | Settings |
|---|---|---|---|
| App embeds | **Bitsy Auto design** | Embed (head) | 61 |
| App embeds | **Bitsy Auto product cards** | Embed (head) | 31 |
| App embeds | **Vehicle nav bar** (+ My Garage popup) | Embed (body) | 73 |
| Add section / Add block → Apps | **Vehicle selector** | App block | 48 |
| Add section → Apps | **Vehicle search hero** | App block | 61 |
| Add section → Apps (collection templates) | **Collection vehicle bar** | App block | 69 |
| Add section → Apps (page templates) | **Vehicle parts results** | App block | 68 |

The two design embeds set CSS variables on `:root`; each block's own colours override them, and a block colour left blank uses the design embed's. Admin-app settings (VIN limit, results page, enabled filters, garage size, save VIN) live in the app and are read through `app.metafields`.

## Bitsy Auto design (embed)
- **Typography:** use theme fonts, heading and body font pickers, text / label / button sizes, heading letter spacing, line height, heading / label / button text case.
- **Colours:** heading, text, labels, links; dropdown background, text, border, not-ready background and text; focus ring; primary button background, text, border, hover background, hover text; secondary button the same five; garage count background and text; success and error.
- **Dropdowns:** height, corner radius, border width, inner padding, auto-advance; Make/Model/Year/Engine labels and placeholders; incomplete message.
- **Buttons:** height, corner radius, border width, side padding, font weight.
- **VIN search and My Garage:** VIN link, back-to-dropdowns text, VIN placeholder, VIN-paused message, My Garage button text, garage icon size; custom CSS for all Bitsy blocks.

## Bitsy Auto product cards (embed)
- **Cards:** image ratio, image fit, second image on hover, show brand / SKU / stock / fit label / add to cart, after add to cart, text alignment, grid gap, card padding, radius, border width, shadow.
- **Text:** fit label, add to cart, added, out of stock, in stock, part-number prefix.
- **Colours:** image background, card background, border, title, price, button background and text, fit label background and text, out-of-stock text.

## Every block (shared groups)
- **Layout:** full width, max width, padding top / bottom (desktop and mobile), padding left-right (desktop and mobile), margin top / bottom, alignment, gap, heading size (desktop and mobile), show on desktop / mobile, extra CSS class.
- **Colours (overrides):** background, background gradient, heading, text, labels, links, button background and text, secondary button and garage text and border, garage icon.
- **Vehicle form:** dropdown layout (row / 2 × 2 / stacked), show labels, button text, search icon, button width (desktop and mobile), show VIN search, show My Garage, garage icon only, show count, prefill the selected garage vehicle.

## Own settings
- **Vehicle nav bar:** position (below / above header), sticky, shadow while stuck, heading, heading on mobile, mobile style (full / collapsed button), collapsed button text, bottom border width and colour, hide on 9 page types; **My Garage popup:** title, empty message, add / save / cancel / selected / shop / full texts, show KType line, show 'VIN saved', popup width, radius, background, text, overlay colour and opacity.
- **Vehicle selector:** heading, subheading, box style, background, text, border, radius, padding, shadow.
- **Vehicle search hero:** desktop and mobile images (focal point), overlay colour and opacity, height presets or custom (desktop and mobile), horizontal and vertical content position, content width; heading, subheading, secondary link; panel style (card / glass / none), panel background, opacity, text, padding, radius, shadow.
- **Collection vehicle bar:** heading, fits message, count text, change / clear texts, no-results message, auto filter, sticky, theme grid selectors to hide; box; product grid (below).
- **Vehicle parts results:** show vehicle bar, vehicle bar heading, heading, count text, no-vehicle message, no-results message, contact link; box; product grid.
- **Product grid (collection bar and results):** columns desktop (2–5) and mobile (1–2), products per page, let shoppers change columns and per page, pagination (numbers / load more / infinite), load-more text, show sort, default sort, filter layout (sidebar / drawer), sidebar side, filter counts, filters heading, clear text.

## Shopify limits
- 75 settings and 6 headers/paragraphs per block or embed (checked by the build script).
- 100 KB of Liquid across the extension (currently about 70 KB).
- `bitsy.js` is loaded with a deferred script tag rather than the schema `javascript` key, which is suggested to stay under 10 KB.
